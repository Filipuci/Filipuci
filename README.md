### Sobre Mim

Comecei querendo criar jogos. Acabei me apaixonando por front-end, tinha algo de mágico em ver uma div virar um elemento na tela. Hoje desenvolvo com React e TypeScript, focado em criar interfaces intuitivas, acessíveis e fáceis de manter.

Minha experiência como Assistente de Suporte Técnico na K2 Network me deu uma base sólida para entender problemas de conectividade, investigar incidentes e me comunicar bem entre equipes. Trago essa bagagem de resolução de problemas direto para o meu fluxo de desenvolvimento de software.

* **Localização:** São Bernardo do Campo, SP
* **Interesses:** Front-End, UI/UX
